# 인계: "슬롯(칸) 모델"과 도형→VLM 전달 (미구현 부분)

작성 기준: 박스·표 보완까지 끝낸 상태(pytest 193 통과). 아래는 **하지 못한 것**과 이어서 할 때 필요한 정보다.

## 이미 된 것 (건드리지 말 것)
- 줄 번호 방식(VLM은 줄 id만), 칸 쪼개기(`extract.py` `_find_gutters` 등: 카드/2단/신문형 다단/도형 경계), 병합 머리·열 지표·소계/합계·라벨 열(`table_header.py`, `data_select.py`), 날짜(YYYY.MM) 유지·retime, `{수치}` 누출 방지.
- 채점: `python tools/eval_golden.py [--ai] [--no-split] -v` (정답 `tests/golden/hard.json`, 영역 기반). 현재 규칙 기준 어려운1 61%/어려운2 69%, VLM 기준 92%/61%.

## 못 한 것 (우선순위순)
1. **슬롯 모델(3절)**: 숫자마다 {slot_id, role, metric, scope, period, compare, agg}. 지금은 문장(`_fill_sentence`)이 "첫 {수치}=현재값, 이후=비교 단어 순서" 가정, 카드(`_numbercards`)가 이름에서 지표만 찾는다.
   - 코드(extract.py)에서 숫자 글자별 원본 형식(부호 ▲△+-, 소수 자리, 쉼표, 단위 억/%/%p/건/p)을 읽어 슬롯에 담기. 값은 AI로 보내지 않음.
   - VLM 응답에 슬롯별 항목 추가(허용 목록 검증은 코드: METRIC_COL 키+DERIVED, info["orgs"], 기간/비교 목록). 목록 밖·모순 조합은 버리고 `slot_unresolved` 플래그.
   - 계산은 `_bases/_val/_metric_table/q_gap_count/q_explanation_count` 재사용. 표시는 원본 형식 유지, ▲↔▼ 부호 전환. DB로 못 구하면 "데이터 없음"(추측 금지). `_fill_sentence`는 슬롯 정보가 없을 때의 대비책으로 남길 것.
   - 숫자 카드: delta_abs, delta_pct(현재/기준−1), %p, count. 이익률은 DERIVED에 정의가 있는지 먼저 확인.
   - 어려운2 정답: 큰 카드 128.4=영업이익·전사·value, +4.2=delta_abs·compare=계획, ▲3.1%=delta_pct·compare=전월. 매출·비용·이익률 카드는 비교 기준이 글자에 없으면 compare=null → 노란색. DB 지표는 매출·영업비용·영업이익(이익률 없음 → "데이터 없음").
2. **차트 축 의미**: 가로축(월 6~11월)·지표·기간을 읽어 막대 값을 DB로, 눈금(120, 60)은 코드가 다시 계산. 현재 `_chart`는 조직별만 가정.
3. **도형을 VLM 목록에 전달(2-2)**: `extract.py`에 `_boundary_edges`(바깥 경계)까지만 있다. 도형 id/크기/채움 여부를 `_line_rows`처럼 VLM에 보내고 박스=줄+도형 합집합으로 하면 "글자 없는 그림칸·차트 막대" 박스가 가능. 도형 수 상한과 `shapes_truncated` 플래그 필요.
4. **재귀 XY-cut(2-1)** 일반화(가로 제목이 단을 가로지르는 구조): 지금은 세로 띠 추적 방식이고 어려운1에서는 동작하지만 단 전체 제목이 단 사이로 이어지는 더 복잡한 구조는 미검증.
5. **표 본문 첫 열 세로 병합(rowspan) 격자**(2-3)와 **선 도형 기반 칸 경계**.
6. **검증 추가(2-4)**: 줄이 정확히 한 블록에 속하는지(이미 부분 구현: vlm_missed/kind_ambiguous), `box_overlap` 플래그(미구현).
7. **화면(3-5)** 슬롯 검토 UI: 미구현.
8. 정답 세트 확장: 신규1~5·원본 2개는 정답 없음(사람 확인 필요), 슬롯·값 정답 없음.

## 알려진 한계
- VLM이 호출마다 다르게 묶는다(어려운2에서 비용·Gap 카드를 한 블록으로 묶거나 소명 목록 줄을 잘못 묶는 경우). 박스 위치는 정확하지만 묶음이 틀릴 수 있고, 줄이 떨어져 있으면 경고만 붙는다.
- 칸 쪼개기 임계값(24pt, 문장 폭 80/110pt, 16pt 신문형 하한, 도형 경계)은 샘플 약 18개로 정한 값. 라벨-설명 2열 목록·줄바꿈이 있는 2열 표는 오탐 가능(finance +7줄, EDA +7줄 정도).
- 합계는 원 단위 값의 합이라 표시값(소수 1자리)의 합과 0.1 차이가 날 수 있다.
