# 경영팀을 부탁해 — 프론트 프로토타입

2026-11-23 고도화와 검증 범위·남은 API/NFR 과제는 [프론트 점검 기록](REVIEW.md)을 참고한다. 아래 최초 브라우저 검증 기록은 11월 18일 시점이며, 후속 왕복 검증 결과는 점검 기록에 있다.

2026-11-18 기준 `프론트 임시v1`의 최신 디자인을 Vue로 옮긴 로컬 체험 버전이다. 기존 API 연결용 `src/App.vue`와 라우트는 보존하고 별도 엔트리로 실행한다.

## 실행

```sh
cd frontend
npm ci
npm run dev:prototype
```

접속: `http://127.0.0.1:5173/prototype.html#/login`

| 역할 | 체험 이메일 | 체험 인증코드 |
| --- | --- | --- |
| 경영기획팀 | `kim.plan@sk.com` | `123456` |
| 조직 담당자 | `choi.infra@sk.com` | `123456` |

고정 인증코드는 체험용이며 서버 인증이 아니다. 실제 이메일은 발송하지 않는다. 미등록 이메일은 화면 전환 없이 입력 아래에 경고를 표시한다. 로그인 정보와 예시 업무 상태는 Pinia 메모리에만 두며 새로고침 시 초기화된다.

## 연결한 흐름

1. 로그인 → 역할별 메뉴. 로그아웃 확인 팝업.
2. 전사 손익 홈 → 월간/연간 할 일과 해당 화면 이동. 이번 달/올해 선택 → KPI·요약·원인 그래프·사업부별 수치 변경. 손익 흐름 워터폴은 원본 예시라는 별도 표시를 유지한다.
3. 월간 시트 관리 → 조직별 월간 제출/소명 상태 → 행 아래 회신 → Gap 계산.
4. 계산기 → 기준/비교 대상과 비교 유형 선택 → 차이율·금액 독립 켜기/끄기 → 적용 → 대·중·소·상세 계층형 결과.
5. 검색·단위·정렬·상태 필터. CSV 내려받기. 선택 해제·제외.
6. 선택 항목 검토하기 → 해당 사업부 하위 메뉴·처리할 셀 건수 → 담긴 항목 검토 → 셀 단위 버전 비교.
7. 화면을 가리지 않는 소명 메시지 패널 → 기한·메시지 입력 → 예시 요청 저장 → 첫 조직 목록 복귀·사업부 탭 제거.
8. 조직 담당자 요청함 → 파일 선택 또는 소명 작성 → 필수 소명 제한 → 예시 회신 → 이력. 파싱과 파일 제출은 서버 미연결 상태로 제한한다.
9. 알림 유형/안 읽음 필터·모두 읽음·대상 조직 이동. 연간 요청·조직별 회신·수락 예시. 조직 아카이브·보고서 시작/직접 자료 틀 편집.

연간 계획과 월간 업무는 별도다. 항목 체크·장바구니 담기는 요청 발송이나 승인으로 처리하지 않는다. 필터 변경은 이미 담긴 비교 스냅샷을 덮어쓰지 않는다. 소명 회신은 숫자·파일·승인 마스터를 바꾸지 않는다.

## 구현 경계

- 모든 화면 수치·첨부·버전은 디자인 예시다. 사용자 첨부 엑셀의 실제 값은 포함하지 않았다.
- 프로토타입의 요청·회신·수락은 메모리에서만 상태가 바뀐다. 운영 데이터에 대한 API 요청은 하지 않는다.
- Excel 선택은 파일명·확장자 확인까지만 지원한다. 파서가 연동된 것처럼 진단·제출 완료를 만들지 않는다.
- Gap 다운로드는 UTF-8 BOM CSV이며 `.xlsx` 생성이 아니다.
- 버전 비교표의 원천 셀과 금액 분할은 화면 구성을 위한 합성 예시다. 실제 파서의 셀 대응 결과가 아니다.
- 실제 인증, 원본 첨부 다운로드, 실제 요청 발송, 승인·master 발행, AI PDF 분석·SQL·최종 보고서 내보내기는 이 프로토타입에 연결하지 않았다. 최신 서버 구현이 없다는 의미는 아니다.
- 소명 메모는 요청별로 보존한다. 조직 담당자는 자신의 조직 요청만 표시한다. 프론트 가드는 실제 서버 권한 검사를 대체하지 않는다.

## 구조와 출처

- `src/prototype/PrototypeApp.vue`: 공통 셸·체험 인증
- `src/prototype/MonthlyPanel.vue`: 월간 계산·조직별 검토·셀 비교
- `src/prototype/HomePanel.vue`: 전사 손익 홈
- `src/prototype/OrgPanel.vue`: 조직 담당자
- `src/prototype/ManagementPanels.vue`: 알림·연간 계획·조직별·보고서
- `src/prototype/store.js`: 예시 업무 상태. `domain.js`: 금액 조건·비교·스냅샷 식별
- `src/lib/decimal-display.js`: 저장소의 정밀 금액 표시 함수를 재사용
- `public/assets/`: 저장소 원본 SVG 및 피그마 아이콘. Noto Sans KR과 OFL 라이선스를 로컬 보관

기반 코드: `shinharyeong/PL_Management_Skala`, `develop` 커밋 `4adb419d7c6ac2bdec03e76f5b5e76d6d6e365f0`. 기존 Vue 3·Vite·Vue Router·Pinia를 유지하며 UI 라이브러리와 Tailwind를 추가하지 않았다.

## 검증

```sh
npm run test:prototype
node scripts/check-prototype-views.mjs
npm run build
```

금액 조건·장바구니 스냅샷·소명 상태·알림을 Node 테스트로 확인한다. SSR 검사는 15개 화면의 템플릿과 store 연결을 렌더링한다. 원본 API용 앱도 다중 엔트리 빌드에 포함한다.

브라우저에서는 미등록 이메일 경고 → 체험 인증 → 전사 손익 홈 → 월간 목록 → 계산 전 화면을 확인했다. 이후 브라우저 제어가 사용자 조작으로 중단되어 계산 후 전체 흐름·모바일의 실제 브라우저 검증은 완료하지 않았다. 이 범위는 상태 테스트·템플릿 렌더·빌드 검증과 구분한다.
