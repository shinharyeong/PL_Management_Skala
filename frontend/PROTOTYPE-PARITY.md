## 서버 계약에 따라 남겨 둔 차이

- 보고서 API가 없어 분석·저장·데이터 조회·내보내기는 사용할 수 없습니다. 가짜 저장 틀이나 결과를 채우지 않았습니다.
- 홈 API의 변동 원인은 사업부별이며, 워터폴은 영업이익까지만 제공합니다. 원본 예시의 계정별 원인·순이익을 임의로 추가하지 않았습니다. 연간 조회는 서버가 반환하는 누계 실적입니다.
- 버전 비교의 산출 근거·업로드 소명은 서버가 최근 자료 기준으로 제공합니다. 과거 버전마다 복제하지 않고 비교표 아래 별도 영역에 둡니다.
- 월간 Gap 조회는 서버의 고정 기준을 사용합니다. 기준 버전 임의 변경과 필터 결과 전용 엑셀 내보내기는 지원 범위대로 제한합니다.
- 조직 담당자 소명은 실제 항목별 저장 API를 사용합니다. 원본의 일괄 회신 버튼을 만들어 서버 작업을 한 것처럼 보이지 않게 했습니다.
- 과거 월 알림에서 이동하면 이번 달 목록이라는 안내를 표시합니다. 현재 월 알림은 해당 조직 행을 펼치고, 연간 알림은 요청 연도를 선택합니다. 과거 월 전체 요청 선택 기능은 별도 구현이 필요합니다.

## 확인

빌드 및 자동 테스트 33개 통과. Chrome에서 원본과 연결본의 알림 배치를 비교했고 실제 52건 목록, 빈 소명 회신 필터, 150%/175% 확대 시 배치를 확인했습니다. 홈·연간 계획·조직별 현황·보고서·사업부15의 월간 계산 결과와 셀 버전 비교 화면도 실제 데이터로 확인했습니다. 조직 담당자 변경은 컴파일 및 DTO 계약을 확인했으며 이번 검수에서는 새 업로드/제출/승인을 실행하지 않았습니다.
