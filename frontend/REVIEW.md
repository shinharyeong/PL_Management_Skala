## 판단

기존 프론트를 처음부터 다시 만들 필요는 없다. `/`의 API용 앱에는 인증·제출·월간 비교·작업공간·401 처리 등이 이미 있다. `/prototype.html`은 피그마를 표현하는 별도 메모리 체험 앱이다. 이번 수정은 후자에만 적용된다. 디자인 표현과 API 앱의 검증된 동작을 통합하는 후속 작업이 필요하며, 이번 수정은 서비스 개발 전체 완료가 아니다.

Figma 로그인·홈·월간 계산기의 디자인 컨텍스트와 렌더를 읽고 기존 구조·색상·로컬 자산을 유지했다. 전체 프레임과 최신 보고서 편집 화면의 픽셀 단위 일치까지 검증한 것은 아니다.

## 검증

`cd frontend`에서 실행:

```sh
npm ci
npm run test:prototype
npm run check:prototype
npm run build
```

- Node 테스트 15개 통과: 비교별 상태·소명·불변 이력, 반응형 계산 세션, 제외 처리, KST, 만료·재전송, 역할·직접 URL 가드.
- 15개 화면 SSR 렌더 통과. 기존 API 앱과 체험 앱 모두 Vite 빌드 통과.
- 로컬 Playwright로 Edge/Chrome 1440×1000에서 인증→계산→다른 비교 중복 셀 담기→소명 요청→역할 변경→개별 작성→확인/수정→제출 이력 검증. 파일 교체·제거, 역할 직접 URL도 확인. 런타임 오류 0건.
- Edge 1920×1080에서 연간 알림 3개 조직·과거 기한 거부·PDF 선택/빈 파일 교체·4개 주요 화면 페이지 넘침·로그아웃 Escape 확인.
- UTC 및 미국 시간대 브라우저에서 실행. 날짜 파싱은 별도 KST 회귀 테스트로 확인.
- axe WCAG A/AA 자동 검사: 홈·월간 목록·연간·보고서 시작·소명 작성의 검사 상태에서 위반 0건. 전체 화면·스크린리더 적합성 인증은 아니다.
- UI 스크린샷·브라우저 검사 결과는 로컬 산출물로 제공한다. 실행 결과와 원본 PRD 파일은 저장소에 포함하지 않는다.

브라우저 검증에서 최초 월간 세션의 반응형 참조 누락과 FileList 초기화 문제를 발견·수정했다. SSR/단위 테스트만으로 UI 완료를 판단하지 않는다.
