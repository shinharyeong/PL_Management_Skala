# 화면 문구 편집

## 화면에서 바로 수정 (권장)

1. 로컬 개발 서비스 http://127.0.0.1:14175 를 엽니다.
2. 화면 왼쪽 아래 **문구 우클릭 편집 · 켜짐**을 확인합니다.
3. 바꾸려는 제목·버튼·안내문 글자 위에서 **우클릭**합니다. 편집할 수 있는 문구는 마우스를 올리면 점선이 나타납니다.
4. 문구를 입력하고 **저장**합니다. Ctrl+Enter 또는 Cmd+Enter로도 저장할 수 있습니다.
5. ui-copy.json 파일에 바로 저장되며 화면에 즉시 반영됩니다. 로그인·작성 중 상태는 유지됩니다.
6. **직전 수정 되돌리기**로 마지막 저장 한 건을 원복할 수 있습니다. 취소·Esc는 저장하지 않고 닫습니다.

같은 문구 항목을 사용하는 위치는 함께 바뀝니다. 예를 들어 메뉴명과 화면 제목은 같은 항목을 사용합니다.
업무 숫자·조직명·파일명·서버 응답·상태 코드 및 사용자 입력 데이터는 이 편집 대상이 아닙니다.
조건에 따라 만들어지는 문구, 입력창 placeholder 등은 일부 아직 분리되지 않았습니다. 점선이 나타나지 않는 문구는 별도로 추가 연결해야 합니다.

개발 서버에서만 로컬 저장 API가 활성화되고, 접근은 loopback·동일 출처로 제한합니다.
생산 빌드에는 편집 UI와 저장 API가 포함되지 않습니다. 다른 브라우저에서 먼저 같은 항목을 바꾸면 저장 충돌을 알려 덮어쓰기를 막습니다.

## 전체 문구 목록에서 수정

http://127.0.0.1:14175/tools/copy-editor.html 을 Chrome 또는 Edge에서 엽니다.

1. **문구 파일 열기**를 누르고 frontend/src/prototype/ui-copy.json을 선택합니다.
2. 검색으로 문구를 찾고 입력칸을 수정합니다.
3. **파일에 저장**을 누릅니다. 항목 이름은 바꾸지 마세요.

우클릭 편집과 파일 전체 저장을 동시에 사용하면 오래된 파일 내용으로 덮어쓸 수 있으므로, 파일 전체를 편집할 때는 최신 파일을 다시 열어 주세요.
파일 선택/저장을 지원하지 않는 브라우저에서는 **JSON 내려받기**로 저장한 파일로 기존 파일을 교체합니다.

월간 요청 미대상 조직 안내는 monthly / notRequestedMessage입니다. 검색창에 '요청 대상에 포함'을 입력하면 찾을 수 있습니다.
