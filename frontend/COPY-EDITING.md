# 화면 문구 편집

## 화면에서 바로 수정 (권장)

1. 로컬은 http://127.0.0.1:14176/dev, 배포는 서비스 주소 뒤에 `/dev`를 붙여 엽니다.
2. 서버에서 조회된 개발 계정을 선택합니다. 이메일·인증코드 입력 없이 로그인합니다.
3. 왼쪽 아래 **문구 우클릭 편집 · 켜짐**을 확인하고 제목·버튼·안내문을 우클릭합니다. 편집 가능한 문구는 마우스를 올리면 점선이 나타납니다.
4. 문구를 입력하고 **저장**합니다. Ctrl+Enter 또는 Cmd+Enter도 지원합니다.
5. 서버 DB에 공통 문구로 저장되고, 다른 사용자의 일반 화면에도 약 5초 안에 반영됩니다. 백엔드 재시작·재배포 후에도 유지됩니다.
6. **직전 수정 되돌리기**로 마지막 저장을 되돌릴 수 있습니다. 그 사이 다른 사람이 같은 키를 바꾸면 충돌을 알립니다. 취소·Esc는 저장하지 않습니다.
7. **문구 JSON 내려받기**로 기본 문구와 서버 수정이 합쳐진 전체 문구를 내려받을 수 있습니다.

같은 문구 항목을 사용하는 위치는 함께 바뀝니다. 예를 들어 메뉴명과 화면 제목은 같은 항목을 사용합니다.
업무 숫자·조직명·파일명·서버 응답·상태 코드 및 사용자 입력 데이터는 이 편집 대상이 아닙니다.
조건에 따라 만들어지는 문구, 입력창 placeholder 등은 일부 아직 분리되지 않았습니다. 점선이 나타나지 않는 문구는 별도로 추가 연결해야 합니다.

일반 화면은 공통 문구를 읽기만 하며 편집 도구는 `/dev`에서만 표시합니다. 저장은 개발 도구가 활성화된 서버의 허용 개발 계정으로 로그인해야 합니다. `/dev` 접근 자체는 인증 경계가 아니므로 현재 캠퍼스 접근 제한을 유지하고 테스트 종료 후 `APP_DEV_TOOLS_ENABLED=false`로 끄세요. 꺼도 이미 저장된 공통 문구는 계속 조회됩니다.

원본 JSON 파일이나 localStorage를 덮어쓰는 방식이 아닙니다. PostgreSQL `ui_copy_override`에 키·문구·수정 버전·수정자·수정 시각을 저장합니다. 충돌 시 취소하고 다시 열어 최신 문구를 확인하세요.

## 전체 문구 목록에서 수정

http://127.0.0.1:14176/tools/copy-editor.html 을 Chrome 또는 Edge에서 엽니다.

1. **문구 파일 열기**를 누르고 frontend/src/prototype/ui-copy.json을 선택합니다.
2. 검색으로 문구를 찾고 입력칸을 수정합니다.
3. **파일에 저장**을 누릅니다. 항목 이름은 바꾸지 마세요.

우클릭 편집과 파일 전체 저장을 동시에 사용하면 오래된 파일 내용으로 덮어쓸 수 있으므로, 파일 전체를 편집할 때는 최신 파일을 다시 열어 주세요.
파일 선택/저장을 지원하지 않는 브라우저에서는 **JSON 내려받기**로 저장한 파일로 기존 파일을 교체합니다.

월간 요청 미대상 조직 안내는 monthly / notRequestedMessage입니다. 검색창에 '요청 대상에 포함'을 입력하면 찾을 수 있습니다.
