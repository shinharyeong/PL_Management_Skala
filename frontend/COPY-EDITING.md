# 화면 문구 편집

개발 서버가 켜져 있으면 http://127.0.0.1:14175/tools/copy-editor.html 을 Edge 또는 Chrome에서 엽니다.

1. **문구 파일 열기**를 누르고 `frontend/src/prototype/ui-copy.json`을 선택합니다.
2. 검색으로 문구를 찾고 입력칸을 수정합니다.
3. **파일에 저장**을 누른 뒤 서비스 화면에서 확인합니다. Vite가 변경을 반영합니다. 로그인 화면으로 돌아가면 다시 로그인합니다.

파일 선택/저장을 지원하지 않는 브라우저에서는 **JSON 내려받기**로 저장한 파일로 기존 `ui-copy.json`을 교체합니다. JSON을 직접 편집해도 됩니다. 예: `"reviewSelected": "선택 항목 검토하기 →"`에서 오른쪽 문구만 변경합니다.

현재 범위: 사이드바 메뉴와 문서 제목, 연결된 정적 화면 제목, 로그인·로그아웃 안내 일부, 월간 관리 주요 버튼·입력 제목. 모든 문구를 분리한 것은 아닙니다. 인증코드 전송 등 조건에 따라 바뀌는 문구와 서버 응답/업무 상태명/데이터 항목명은 기존 경로를 유지합니다. 파일의 항목 이름을 지우거나 바꾸지 마세요. 이 편집기는 개발용 도구이며 운영 사이트 메뉴나 빌드 진입점에 추가하지 않습니다.

개발 중 저장은 로컬 소스에 반영됩니다. 다른 컴퓨터·배포 화면에도 적용하려면 변경 파일을 Git에 반영하고 재배포해야 합니다. 피그마에는 자동 반영되지 않습니다.
